# userflow

App iOS (**SwiftUI**) para explorar un listado de usuarios desde **[JSONPlaceholder](https://jsonplaceholder.typicode.com)**, combinado con **persistencia local en Realm**, edición, alta y borrado lógico, validaciones y **ubicación cuando se crea un usuario**. Arquitectura **MVVM + Coordinator**, red con **Alamofire**, concurrencia con **async/await**, **iOS 15+** y texto en **español e inglés**.

El detalle técnico, el orden de trabajo y los criterios por ticket están en [`docs/development-plan.md`](docs/development-plan.md). **`CHANGELOG.md`** resume versiones/build por hito.

Este README cubre solo el contexto general; el **README de producto** (instrucciones, decisiones finales de arquitectura y uso) conviene escribirlo al **cerrar el alcance** y abrir el **pull request `develop` → `main`** (véase ticket **MT-13** del plan).
